# Security Policy

The project takes security issues seriously and appreciates responsible reports from the community.

## Supported Versions

The current 3.x release line is the primary supported version. Older versions may not receive security updates or maintenance.

## Reporting a Vulnerability

Do not report an undisclosed vulnerability through a public GitHub issue.

Prefer GitHub's private vulnerability reporting or a private Security Advisory for this repository: [Report a vulnerability](https://github.com/yalin28/vue-antdesign-admin-template/security/advisories/new).

Please include:

- A clear description of the vulnerability.
- The affected version or commit.
- Steps or a minimal example to reproduce the issue.
- The potential impact.
- A suggested fix or mitigation, if available.

No fixed response SLA is promised, but maintainers will make reasonable efforts to review, communicate about, and address valid reports. Please avoid public disclosure until a fix or coordinated disclosure plan is available.

This policy primarily covers code maintained in this repository. Vulnerabilities in third-party dependencies should generally be reported to the relevant upstream project first; reports are still welcome when a dependency issue has a specific impact on this project.
